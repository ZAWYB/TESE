# Git 学习与测试仓库 (Git Test Sandbox)

## 📑 仓库简介
这是一个专门用于学习、练习和测试 Git 版本控制命令的“沙箱”仓库。
在这里可以安全地进行任何代码提交、分支合并或版本回退的实验，完全不必担心破坏任何实际的工程项目。

## 🎯 主要用途
建立本仓库的核心目的包括：
1. **基础命令练习**：熟悉 `git add`、`git commit`、`git push`、`git pull` 等日常工作流。
2. **分支管理模拟**：练习如何创建新分支 (`branch`)、切换分支 (`switch`) 以及合并分支 (`merge`)。
3. **冲突解决演练**：人为制造代码冲突，并练习如何查看差异 (`diff`) 和解决冲突。
4. **版本回滚测试**：安全地测试 `git reset` 和 `git revert` 等高阶命令的实际效果。

## 💡 使用说明
* 这是一个纯测试环境，请随意在此仓库中创建、修改或删除文件。
* 即使弄乱了提交历史也没关系，这正是本仓库存在的意义。
